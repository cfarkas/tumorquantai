# Output schema

The exact current schema moved to
[Output directory and file schema](reference/outputs.md).

Start with:

```text
START_HERE.html
<sample>/overlays/celltypes_overview_and_zoom.png
<sample>/summary/summary.json
aggregated_celltypes/sample_aggregation_audit.csv
aggregated_celltypes/celltype_fractions_by_sample.csv
```

The combined overlay filename is exactly
`celltypes_overview_and_zoom.png`. Counts/fractions contain completed samples;
the audit retains failed and incomplete samples.
