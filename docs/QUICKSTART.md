# Quick start

This stable URL points to the task-specific guides:

- [Structural software demo](start-here/demo.md)
- [Public one-slide quickstart](start-here/public-slide.md)
- [Inspect and run your own slide](start-here/own-slides.md)

The shortest safe start is:

```bash
git clone https://github.com/cfarkas/tumorquantai.git
cd tumorquantai
./tumorquantai demo
```

Expected output includes `TumorQuantAI structural demo complete.` and an
absolute `Open first` path ending in
`tumorquantai-demo/START_HERE.html`. No HistoPLUS inference runs and fixture
values have no biological meaning.
